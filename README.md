# BRM

Scripts and data for

> Li, J., Patz, R. J., & van der Linden, W. J. OptimalCAT: Bayesian adaptive testing with optimal test assembly. *Behavior Research Methods*.

The OptimalCAT software is available at www.optimal-cat.com.

| Folder or file | Contents |
|---|---|
| `EmpiricalExample/` | The Empirical Example: configurations, simulated responses, engine outputs and scripts for Table 2 and Figures 3–6. See its README. |
| `Multi-Section Adaptive Design Framework - MST Example/`, `mst.xlsx` | The multi-section (two-stage) example. |
| `Application Example/`, `math.xlsx`, `read.xlsx` | The mathematics and reading test configurations. The Empirical Example's workbooks are derived from `Application Example/math_bayesian.xlsx`. |
| `Figure 3 Table 2/` | Solver comparison runs (FICO Xpress and Gurobi) from an earlier version of the manuscript. |
